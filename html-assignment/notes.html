HTML Tags

  • h1-h6: These tags created headers. "h1" is the biggest size header and "h6" is the smallest.
  • p: This is the paragraph tag. This tag allows us to write text.
  • br: This is the break tag. This tag allows us to move down on the page and help break up text.
  • img: This tag allows us to put images into the web page.
  • a: This tag allows us add links by refrencing pages using href.
